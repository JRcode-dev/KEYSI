- React Native.

## 5. CONFIGURACIÓN DEL SERVIDOR

Configura NestJS con:

- Prefijo global `/api/v1`.
- Puerto predeterminado 3001.
- Puerto configurable mediante `PORT`.
- CORS configurable mediante variables de entorno.
- Helmet.
- Validación global con ValidationPipe.
- Transformación automática de DTO.
- Rechazo de propiedades no permitidas.
- Manejo centralizado de errores.
- Logs estructurados.
- Configuración centralizada y validada.

El servidor debe poder ejecutarse independientemente del frontend.

## 6. POSTGRESQL Y PRISMA

Prepara la conexión con PostgreSQL mediante Prisma.

Requisitos:

- `DATABASE_URL` mediante variable de entorno.
- Archivo `.env.example` sin credenciales reales.
- Cliente Prisma centralizado como proveedor de NestJS.
- Conexión y desconexión controladas mediante el ciclo de vida de NestJS.
- Esquema inicial válido.
- Comandos para generar el cliente y ejecutar migraciones.

No inventes credenciales de base de datos.

Si Replit no proporciona una base PostgreSQL disponible, deja configurada la integración y explica exactamente cómo conectarla. No declares que la base de datos está conectada si no se ha comprobado.

- Eventos de regalos.

Establece como regla arquitectónica que los futuros eventos económicos solo se emitirán después de confirmar la transacción correspondiente en PostgreSQL.

## 9. REGLAS ARQUITECTÓNICAS DE KEYSI

Desde el principio, prepara el backend para cumplir estas reglas:

- El frontend nunca será la fuente de verdad de los saldos.
- Ningún módulo de negocio podrá modificar directamente los saldos.
- Las operaciones económicas futuras deberán centralizarse en LedgerService.
- Las operaciones económicas deberán utilizar transacciones de base de datos.
- Se utilizarán identificadores de idempotencia para evitar operaciones duplicadas.
- Los registros económicos serán inmutables.
- Las correcciones se realizarán mediante movimientos compensatorios.
- Los cálculos monetarios utilizarán enteros, nunca números decimales de punto flotante.
- Los secretos nunca se almacenarán en el repositorio.
- Las contraseñas nunca se almacenarán en texto plano.

Estas son reglas de arquitectura; no implementes todavía las operaciones económicas.
